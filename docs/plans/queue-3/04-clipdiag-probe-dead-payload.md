# 04: onto-doc-матрица: проба порядка redact → срез мертва

**What to build:** проба порядка `redact → срез` в tests/onto_doc_matrix.mjs
(блок clipDiag) обязана краснеть на инверсии порядка и на полном снятии
редакции — сейчас она зелёная в обоих случаях, потому что секрет в payload
целиком лежит за позицией среза 80 и в срез не попадает ни при каком порядке.

**Blocked by:** —.

## Поставка (2026-10-16, v0.5.61)

Payload переставлен с `'y'×70` на `'y'×60`: секретный литерал
`FAKEjsonsecret99` — индексы 74–89 (FAKE-префикс 74–77 внутри среза 80,
закрывающая кавычка значения 90 и `}` 91 — за срезом), контрфакт конфирмера
воспроизведён живьём (`indexOf`, node -e). Прежний payload держал секрет на
84–99 — за границей среза при любом порядке, наблюдение dwfrun-7f851f1e.

Мутационные пробы самой пробы встроены в блок clipDiag: инверсия
(`redactLite(payload.slice(0, 80))`) и снятие redact (`payload.slice(0, 80)`)
обязаны содержать FAKE-фрагмент, иначе fail «МУТАНТ-ЗЕЛЁН — проба мертва».
Счётчик кейсов clipDiag +3 → +5 (эталон, длина, инверсия, снятие, n).

Живые прогоны: эталон `функций: 5, кейсов: 67, упало: 0` rc=0; мутант живого
воркфлоу `redactLite(s.slice(0, n))` — УТЕЧКА clipDiag rc=1; мутант
`s.slice(0, n)` — УТЕЧКА clipDiag rc=1 (каскад по curatorResult/piecesGate
ожидаем); возврат мёртвого payload — 2×МУТАНТ-ЗЕЛЁН rc=1 (мета-проба ловит
смерть). pytest 322 passed, lint --strict чист.
