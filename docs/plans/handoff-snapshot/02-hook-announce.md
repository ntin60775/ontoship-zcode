# 02: Хук — анонс слепка без TTL и миграционный фолбэк

**What to build:** SessionStart-хук при наличии `.scratch/handoff-current.md`
анонсирует его независимо от возраста файла — старый слепок означает, что работ
не было, анонсировать его тем более надо. Формулировка анонса отражает суть
(«слепок состояния проекта»), глубина, которой в файле нет, —
`ReadSessionContext` по id из `From:`-строки с прежней валидацией формата и
честной формулировкой при нераспознанном id. При отсутствии слепка — прежнее
поведение без изменений (новейший legacy `handoff-*.md` по mtime при возрасте
< 7 дней) как миграционный путь, пока старые файлы не зачищены тикетом 03.
Глоб `handoff-*.md` имя `handoff-current.md` не матчит — в хуке явная проверка
имени, а не расширение глоба.

**Blocked by:** 01 (анонсировать файл, который ещё никто не пишет, бессмысленно;
один согласованный переход на новое имя).

- [ ] при наличии `handoff-current.md` анонс идёт по нему независимо от
      возраста файла
- [ ] при отсутствии слепка — прежний legacy-фолбэк (новейший по mtime,
      TTL 7 дней); поведение смены без слепка не меняется
- [ ] id из `From:` валидируется; нераспознанный — формулировка без
      ReadSessionContext (как сейчас)
- [ ] `tests/test_session_start_hook.py` расширен: позитив (слепок любого
      возраста анонсируется, в т. ч. старше 7 дней), негативы (нет слепка —
      фолбэк; невалидный `From:` — честная формулировка)
- [ ] `gitmark lint` + `pytest` зелёные
