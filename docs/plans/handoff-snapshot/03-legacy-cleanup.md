# 03: Зачистка legacy-хэндоффов

**What to build:** после переключения анонса (релиз тикета 02 доезжает до
вендора self-update'ом) разово удалить устаревшие `.scratch/handoff-sess_*.md` —
в `.scratch` остаётся единственный хэндофф-файл, ожидание оператора «хэндофф —
единственный файл со слепком» выполняется буквально. Опс-тикет без кода:
гейта и релиза нет (прецедент queue-2/11), верификация — живой анонс хука
после зачистки. Миграционный фолбэк в хуке сознательно остаётся — безвредный
код, который просто перестаёт срабатывать.

**Blocked by:** 02 (пока анонс не переключён, удаление legacy оставит смену без
слепка вообще без анонса).
