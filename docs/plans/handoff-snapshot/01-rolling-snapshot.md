# 01: Единый катящийся слепок — регенерат из /handoff и автозапись на закрытии тикета

**What to build:** хэндофф становится одним файлом `.scratch/handoff-current.md`,
который всегда содержит полный слепок последнего состояния работы над проектом.
Ручной `/handoff` переписывает его целиком при каждом вызове (регенерат, не
дописка); `/ship` на закрытии тикета (после архивации, шаг 9) делает ту же
автозапись — смена может закончиться чем угодно, а слепок уже стоит. Имя больше
не содержит sess-id — класс коллизий имён исчезает по построению; ветви
«никогда не перезаписывать» и timestamp-fallback из скилла убираются. Маркер
`.session-id` остаётся только источником provenance в штампе `From:`
(best-effort: нет маркера — штамп без id, без отказа). Файл — клей: позиция в
порядке планов, ссылки на коммиты, план и ключи памяти; смысловые секции
шаблона (Task, Done, Decisions с evidence, Open, Next, Artifacts) сохраняются,
добавляются штампы `updated:` (дата) и `From:` (источник обновления).

**Blocked by:** None (can start immediately).

- [ ] `/handoff` пишет `.scratch/handoff-current.md`; повторный вызов обновляет
      тот же файл целиком; чужие `handoff-sess_*.md` не трогает и не создаёт
- [ ] `skills/ship/SKILL.md` шаг 9 предписывает автозапись слепка после
      архивации тикета (факты прогона: тикет, релиз/хэши, Open из плана, Next)
- [ ] шаблон несёт `updated:` (дата) и `From:` (сессия/коммит источника
      обновления) как provenance; при отсутствии маркера — запись без id
- [ ] ветви коллизий и timestamp-fallback убраны из скилла; границы
      (эфемерность `.scratch`, клей-не-дубликат, хэндофф не KB-док, чистка
      legacy старше 7 дней) записаны
- [ ] `gitmark lint` + `pytest` зелёные
