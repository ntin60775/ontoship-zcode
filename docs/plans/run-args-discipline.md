# Транспортная дисциплина args — префлайт перед сабмитом рана

## Goal

Ошибки транспорта аргументов (пустой обязательный arg, JSON-тип строкой вместо
массива, двоеточие в YAML-шапке, кавычные промахи) не сжигают воркфлоу-раны:
префлайт-проверка перед каждым CreateWorkflow/AmendWorkflow.

## Done

- skills/contour/SKILL.md: раздел префлайта — перед сабмитом рана сверить
  args с YAML-декларацией воркфлоу (все required непусты; json-типы переданы
  настоящими массивами/объектами, не строками; в шапке нет некавыченных
  двоеточий в прозе) + правило «inline-скрипт с args — захардкодь или
  передавай args, но не забудь их передать».
- Урок оформлен от фактов: три сожжённых рана 2026-10-08 (dwfrun-d5330cf3/
  8614335b — args.root не передан, диффы не читались; dwfrun-741b8ae8 —
  findings строкой вместо массива, честный abort конфирмера).
- Память агента (личный слой) уже обновлена; тикет закрывается правкой contour.

## Scope

- `skills/contour/SKILL.md` — один раздел с чек-листом префлайта.

## Constraints

## Context

Ретроспектива 2026-10-08 (решение оператора «да»): три из восьми ранов смены
сгорели на моих ошибках транспорта, а не на существе; процесс честно ловил
каждую (именованные abort'ы), но токены потрачены. Contour — штатное место
поставляемых уроков механики воркфлоу (external-dependencies/03); префлайт —
чистая привычка агента, кода не требует.
