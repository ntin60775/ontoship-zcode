# Транспортная дисциплина args — префлайт перед сабмитом рана

## Goal

Ошибки транспорта аргументов (аргумент вызова не передан; json-тип строкой
вместо массива; двоеточие в YAML-шапке) не сжигают воркфлоу-раны:
префлайт-сверка args перед каждым CreateWorkflow/AmendWorkflow, оформленная
поставляемыми уроками contour.

## Done

- skills/contour/SKILL.md: урок 10 «The host validates args against the
  declaration — nothing more» в канонической форме симптом→причина→действие,
  с реальными симптомами инцидентов 2026-10-08 (ран отчитал «диффы не
  читаются» — args не переданы; confirm честно абортировался — findings
  строкой); Do-блок — чек-лист префлайта со ссылками на уроки 1/2/3/9:
  сверка с тем, что скрипт реально читает в этом вызове (required-декларация
  — только нижняя граница: `root` объявлен `required: false` и молча
  дефолтится — required-сверка пропускает инцидент); каждый семантически
  нужный args.X передан и непуст; json-типы — структурными значениями, не
  предсериализованными строками; строки — `JSON.stringify`, не руками;
  двоеточия в шапке — в кавычках; скрипту нужны args — `path` со шапкой,
  инлайн — без args; ревизия с изменившимся контрактом — свежий
  CreateWorkflow.
- Урок 11 «node -e eats the `--` separator» (симптом — конверт вызова не
  долетает, ловился гейтом v3): шаблон
  `world.run("node", ["-e", script, "--", json])` — последний элемент argv
  есть конверт, поиск `--` давал −1; direct-фолбэк линз зависит от этого
  шаблона — урок едет вместе с уроком 10 (challenger R4).
- frontmatter description contour дополнен триггером «args preflight before
  submitting a run».
- Run-ID инцидентов (dwfrun-d5330cf3, dwfrun-8614335b, dwfrun-741b8ae8)
  живут в этом плане и Context — поставляемый скилл их не несёт (стиль
  уроков 1–9; потребитель чужие раны не откроет).
- `gitmark lint --strict` зелёный; вендор `.zcode/skills/contour` доехал
  self-update'ом; `scripts/deploy-check.sh` exit=0.

## Scope

- `skills/contour/SKILL.md` — уроки 10 и 11 + триггер в description
  (вендор доедет self-update).

## Context

Грилл 2026-10-09 (субагент-грилл + challenger dwfrun-c3a6d4a4):

- Ядро урока 10: хост валидирует args ТОЛЬКО по декларации шапки —
  unknown keys / missing required / wrong types отвергаются, но optional с
  дефолтом проходит молча, а `type: json` принимает строку как валидное
  значение (динамик-workflows SKILL.md:939–941). Семантику «нужен ли этот
  аргумент именно этому вызову» знает только вызывающий — сверка с тем, что
  скрипт реально читает, есть одноразовая мысленная проверка вызывающего,
  не enforcement.
- Инциденты 2026-10-08: dwfrun-d5330cf3/8614335b — inline-скрипту не
  передали args (root пуст, диффы не читались, два рана); dwfrun-741b8ae8 —
  findings строкой вместо массива (честный abort конфирмера). Рамка
  «только required+type» пропускает первый класс — потому ядро шире
  декларации.
- Форма — канонический урок, не безномерный раздел: shipped-контракт
  external-dependencies/03 (каждый урок симптом→причина→действие,
  кросс-ссылки по номерам); симптомы урока 10 — реальные инциденты, не
  гипотетические (возражение challenger о «выдуманном симптоме» снято
  фактической формулировкой).
- Урок 11 добавлен challenger-возражением R4: direct-фолбэк линз
  (lens-substrate-flash) использует этот шаблон — его транспортный урок не
  может оставаться только комментарием в коде.
