# 03: Уроки контура — поставляемый скилл

**What to build:** механика zcode-workflow выучена здесь прогонами 2026-10
ценой сорванных ранов, но живёт только в памяти агента одной сессии —
потребитель плагина в своём проекте собирает те же грабли заново. Новый
скилл `skills/contour/SKILL.md` («уроки контура») вендорится штатным
маппингом `skills/*` (deploy.json не трогается) и несёт проверенные уроки
механики, каждый в форме симптом → причина → действие:

1. AmendWorkflow не переносит args: ревизия рана, чей контракт args
   изменился (добавлен/переименован/обязателен), требует свежего
   CreateWorkflow — аменд стартует ревизию с пустыми args (наблюдено:
   ранний возврат «Тикет не передан»).
2. CreateWorkflow с инлайн-скриптом args не принимает вовсе — args только
   через `path` на файл со `/* zcode-workflow */`-шапкой.
3. Двоеточие с пробелом в YAML-шапке workflow (description, описания args)
   ломает парс сабмита (invalid_yaml) до всякой TS-компиляции; значения с
   двоеточиями — только в кавычках.
4. Апрув воркфлоу безусловен: каждый CreateWorkflow — окно подтверждения
   даже в full-access/yolo; без окна исполняется только AmendWorkflow рана
   своей сессии. «continue» в чате закрывает стоп-пункт диалога, но не это
   окно.
5. Сабагенты воркфлоу несут фиксированный базовый вес запроса (~140k
   токенов: контракт воркфлоу-агента + схемы ВСЕХ инструментов хоста с MCP)
   — против тарифных потолков провайдера первый запрос может не влезать
   независимо от узкости задачи; рычаги — микро-CLI субстрат через
   world.run, меньше MCP в сессии, модель с большим окном. Топология
   (дробление, линзы) историю экономит, базу — нет.
6. Отказ-пути agent() live-неиндусируемы: subagent_model валидируется хостом
   до рана; транзиентные модельные ошибки ретраит рантайм, детерминистские =
   provider-stop всего рана; отказ-ветки покрывать unit-матрицами чистых
   функций и гейтами, в отчёте — «live-неиндусируемо».
7. world.run: имя команды — compile-time литерал (сабмит показывает набор
   команд оператору), рантайм-значения — в args; nonzero exit — обычное
   значение (ветвиться, не ловить); таймаут/спавн-отказ — реджект: если
   отказ — ветка логики, его ловят, а не роняют ран.
8. workflow-.ts исполняются движком без tsc: полная проверка типов — только
   на компиляции хоста при сабмите (первые сабмиты после self-update
   показывают скрытые ошибки); локальный дым — node --experimental-strip-types
   с async-обёрткой (топ-левел return без обёртки — ложный FAIL).
9. Хост args CreateWorkflow не режет: «не распарсился» = битый JSON у
   вызывающего; транспорт проверен до ~25 КБ на аргумент.

Тарифно-специфичное (потолки neuraldeep, конфиг coddy, роли) — не в скилле:
это уровень docs/ops/install.md и /roles, скилл несёт только механику
zcode-примитивов, верную в любом проекте.
