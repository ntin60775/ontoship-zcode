# 01: Контур кредов на zcode; гейт fail-closed

**What to build:** субстрат гейта — прямые вызовы API neuraldeep из
воркфлоу (gate-followups-2/07), и решение оператора 2026-10-07: весь контур
поставки провайдеров/моделей/кредов замыкается на zcode — в него уже введены
провайдеры, карточки моделей и ключи, и roles работает только с моделями,
нормально добавленными в zcode. Никаких ~/.coddy/config.yaml и omp
models.yml в контуре гейта нет (coddy-версия тикета закрыта вместе с
coddy-субстратом). Остаются два хвоста: (1) гейт fail-closed по субстрату —
нет карточки провайдера/ключа в zcode, модель роли не добавлена →
именованная остановка прогона с диагностикой, называющей роль, путь
конфига zcode и недостающее; (2) `docs/ops/install.md` — раздел машинных
пререквизитов (git, node, python3, pytest) и пререквизита «модель ревьюера
добавлена в zcode с карточкой провайдера» с границей ответственности:
раннер вендорит payload, машинные инструменты и креды — уровень машины.

**Blocked by:** None (can start immediately).

- [ ] гейт останавливается с именованной диагностикой при: конфиг
      провайдеров zcode не читается; у провайдера нет apiKey; модель роли
      отсутствует (живые пробы веток)
- [ ] install.md: машинные пререквизиты + «модель добавлена в zcode» +
      граница ответственности раннера
- [ ] `gitmark lint --strict` + `pytest` зелёные
