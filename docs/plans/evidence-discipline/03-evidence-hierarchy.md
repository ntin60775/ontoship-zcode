# 03: Справка «Иерархия доказательств» — уровни с механизмами

**What to build:** справка docs/reference «Иерархия доказательств» в стиле
инвариантов слепого ревью: четыре уровня силы доказательства при проверке
результата агента — мутационная/негативная проба над проверкой; живой E2E-ран
на реальном контуре; зелёный тест с прочитанным логом; утверждение агента
(самоотчёт). Каждый уровень называет механизм, который его держит: confirm-ран
со свежей моделью и пробами; шаг «Prod checks» ship и живые приёмки (self-update
по файлам, A/B); правило телеметрии шага «Tests» и обязательность проб
(отгруженные тикетами 01 и 02); слепота гейта и запрет «согласие без проверки».
Заканчивается чек-листом «каким доказательством принимать тикет».

**Blocked by:** 01 (телеметрия), 02 (обязательность проб) — справка называет их
отгруженные формулировки механизмами, как review-invariants называет воркфлоу.

- [ ] Справка существует (`node_type: reference`), relates_to ведёт на
  review-invariants.md.
- [ ] Каждый из четырёх уровней называет механизм; для уровней пробы и зелёного
  теста — отгруженные тексты тикетов 01/02.
- [ ] Чек-лист выбора доказательства в конце; `gitmark lint --strict` зелёный
  (доковый тикет — лёгкий контур гейта).
