# 01: Телеметрия прогона — лог прочитан, иначе активность, а не факт

**What to build:** поставляемые ритуалы считают прогон тестов фактом приёмки
только вместе с прочитанным логом. В шаге «Tests» ship-скилла прогон сьюта
завершается чтением лога — первый упавший, счётчики, предупреждения; фильтрация
вывода не съедает rc (урок «pytest | tail»); rc=0 без чтения лога — активность,
не факт. В DoD-проходе to-tickets критерием-фактом для «прогона тестов»
объявляется прочитанный лог, а не сам запуск — расширение существующего
«activity rather than an observable fact».

**Blocked by:** None (can start immediately).

- [ ] Правило телеметрии записано в шаге «Tests» ship-скилла: факт — прочитанный
  лог (первый упавший, счётчики, предупреждения); rc=0 без чтения лога —
  активность, не факт; фильтрация вывода не съедает rc.
- [ ] DoD-проход to-tickets называет прочитанный лог фактом для критерия
