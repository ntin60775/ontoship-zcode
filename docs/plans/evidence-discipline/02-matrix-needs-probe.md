# 02: Новая тест-матрица обязана нести негативную/мутационную пробу

**What to build:** шаг «Tests» ship-скилла требует: каждая новая тест-матрица
отгружается вместе с негативной/мутационной пробой — кейсом, который обязан
падать, когда проверяемое поведение сломано; матрица без пробы доказательством
не считается. В правиле названы живые прецеденты практики: redact-матрица
(критерий позитива — отсутствие секрета, не out≠input), verdict-матрица,
проба одноразовости extractParts.

**Blocked by:** None (can start immediately; правит тот же шаг ship-скилла,
что и тикет 01 — едут подряд друг за другом).

- [ ] Правило записано в шаге «Tests»: проба — обязательный спутник новой
  матрицы; кейс обязан падать при сломанном поведении; матрица без пробы —
  не доказательство.
- [ ] Названы прецеденты — не менее двух живых матриц с пробами.
- [ ] Текст — по-английски, в стиле соседних строк; `gitmark lint --strict`
  зелёный; вендор `.zcode/skills` синхронен после self-update.
