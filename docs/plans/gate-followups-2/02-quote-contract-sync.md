# 02: Контракт цитаты: промпт синхронен коду

**What to build:** промпт оси код-ревью перестаёт обещать механику, которой
нет. Сегодня он говорит «несуществующая цитата = несостоявшаяся находка», но
код ничего не отбрасывает: находка без цитаты уезжает в confirm-ран с запасным
evidence («цитаты ось не дала — проверяй по месту where»). Рассинхрон
контракта и поведения — промпт врёт про собственную механику, конфирмер
получает находки, которые по контракту не должны были доехать. Направление
фиксируется на ревью тикета, рекомендация — честная формулировка fallback'а
(«цитату давай всегда; без неё конфирмер пойдёт по месту where»): fallback
уже осмыслен, а enforcement меняет поведение рана. Хвост verified-находки
приёмки gate-followups/02.

**Blocked by:** None (can start immediately).

- [ ] направление выбрано и зафиксировано в ship-заметке: enforcement
      (отбрасывать безцитатные находки честным счётчиком) или правка текста
- [ ] текст промпта оси соответствует фактическому поведению безцитатных
      находок (при enforcement — код отбрасывает и считает)
- [ ] при enforcement: счётчик отброшенных в conclusion, якорь в матрицу
- [ ] `gitmark lint` + `pytest` зелёные
