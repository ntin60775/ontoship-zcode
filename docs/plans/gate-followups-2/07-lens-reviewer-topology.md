# 07: Гейт-ревью — узкие специализированные ревьюеры

**What to build:** `skills/ship/reviewer.workflow.ts` (+ вендор-копия) меняет
ось разбиения ревьюеров: не «один файл диффа на ревьюера», а ростер узких
линз-специалистов — ревьюеров много, каждый ест строго свой маленький кусок
(решение оператора 2026-10-06: прежняя ось — фундаментальная ошибка, не
симптом). Повод: в гейт-прогоне handoff-snapshot/02 ревьюер файла
hooks/session-start.sh (188 строк, дифф ~90 строк) дошёл до 139k токенов входа
при тарифном потолке 138 336 (neuraldeep-sub qwen3.6-unlim-xl, code 400
«Слишком длинный запрос») — ран остановлен провайдером дважды, resume не
лечит: журнал переигрывает раздутую историю актора. Материал аска маленький —
раздувание создал сам агент обходами репозитория поверх своего файла;
усиление персоны (запрет объёмных команд, коммит `68367ea`) симптоматично,
ось «целый файл как кусок» вопрос не закрывает. Хвост из приёмки 02
(confirm-ран 2026-10-06, verified, отложен сознательно до перестройки): батч
измерения `wc -l` теряет диагностику отказа — exitCode/stderr выбрасываются,
весь батч молча получает `-1` (`reviewer.workflow.ts:288-301`); закрыть в
этой же перестройке.

Ростер линз (стартовый, уточняется при реализации): `logic` — инварианты,
границы, потерянные ошибки, exit-коды (дефолт для исполняемого кода);
`security` — недоверенный ввод, инъекции (shell/path/regex), секреты в
выводе; `shell` — quoting, подстановки, семантика `set -euo pipefail`
(только .sh); `concurrency` — гонки, атомарность записи, temp-файлы (когда
дифф трогает процессы/файлы); `tests` — тесты против критериев приёмки,
негативные случаи (только tests/); `docs` — doc↔code синк, ссылки,
frontmatter, устаревшие имена (только .md).

Механика: карта диффа собирается как сейчас (numstat + untracked + wc);
аск линзы = узкое определение с конкретными паттернами багов + контракт
материала (дифф + адресные чтения диапазонов; целиком — только файлы в
пороге contextHint) + запрет объёмных командных выводов. Каждый файл диффа
покрыт минимум одной релевантной линзой (исполняемый → logic, .md → docs);
линза без релевантных файлов не стартует — fan-out соразмерен диффу. Карта
покрытия называет пары файл×линза; именованные пропуски — как сейчас. Форма
находки `{where, claim, evidence, severity}` и confirm-ран не меняются.
`skills/code-review/code-review.workflow.ts` — тот же принцип отдельным
решением, не в этом тикете.

**Смена субстрата (дополнено 2026-10-06 по живой приёмке, пересмотрено
2026-10-07 — решение оператора: прямой API):** узость линз не чинит саму
стену — базовый вес первого запроса сабагента хоста (~140k: контракт
воркфлоу-агента + схемы инструментов хоста с MCP) лежит на тарифном потолке
neuraldeep 138 336, приёмка линз на сабагентах повторила срыв (142 217,
reviewer-logic). Промежуточный субстрат coddy вскрыл четыре собственных
отказа (tool-блуждание по репо вопреки запрету, кап ходов 30, thinking-пожор
тарифного вывода 8000/ответ, конфиг-синк ~/.coddy как новая зависимость) —
осознанный выбор по анализу всех вариантов: ПРЯМЫЕ вызовы API neuraldeep из
самого воркфлоу (world.run node -e с инлайн-скриптом, едущим в файле
воркфлоу — дрейфа версий helper'а нет). Линза — чистая функция «промпт →
JSON», агентность не нужна: вся наблюдаемая агентность была источником
отказов. Контур моделей/кредов замкнут на zcode (решение оператора
2026-10-07): apiKey и baseUrl читаются инлайн-скриптом из карточки
провайдера zcode (~/.zcode/v2/provider_config.json), omp-конфиги и coddy не
участвуют; ключ не попадает ни в argv журналируемых вызовов, ни в stdout.
Диффы инлайном в промпт (бюджет LENS_INLINE_LINES, сверх — именование в
coverage); один файл на вызов; находки — json-блоком с починкой сырых
переносов; парс, один ретрай, таймаут — именованный отказ линзы; обрыв по
тарифному потолку вывода виден как finish=length; redact/счётчики/
coverage/якоря diff_map — без изменений. Confirm-ран не трогается
(GLM-Flash сабагенты хоста помещаются с запасом).

**Blocked by:** None (can start immediately); тикеты 02–04 того же плана
правят тот же файл — мержить последовательно.

- [ ] линза без релевантных файлов не стартует (fan-out соразмерен диффу)

      целиком — только файлы ≤ порога contextHint; запрет объёмных команд
