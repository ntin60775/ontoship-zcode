# 01: Init-блок называет команды короткими именами

**What to build:** verbatim-блок скилла `/init` называет команды короткими
именами (`/kb-search`, `/doc`, `/ship`), как они реально резолвятся в zcode:
скиллы деплоятся в `.zcode/skills/` потребителя и вызываются без префикса.
Сегодня блок пишет omp-форму `/ontoship:*` (порт-дрейф) — fresh-потребитель
получает указания на несуществующие команды. Оговорка «Skill names below use
the plugin prefix» убирается или переворачивается. У уже живущих потребителей
блок мигрирует бесплатно: кейс «оба маркера, блок отличается → заменить только
внутри маркеров» сработает при следующем `/init` без дополнительных механизмов.
Решение ut-10 (ADR в том репо) фиксирует короткую форму как правильную.

**Blocked by:** None (can start immediately).

- [ ] в verbatim-блоке init нет префиксной формы `/ontoship:*`; команды
      короткие; оговорка про префикс убрана или заменена честной
- [ ] сухой прогон на scratch-AGENTS.md с префиксным блоком внутри маркеров
      даёт замену блока на короткую форму; строки вне маркеров не меняются
- [ ] сухой прогон без AGENTS.md создаёт файл сразу с короткой формой
- [ ] `gitmark lint` + `pytest` зелёные
