# 04: extractParts читает файл один раз

**What to build:** tests/diff_map.mjs извлекает каждый файл-копию один раз за
прогон (кэш по пути или переиспользование уже прочитанного) вместо трёх
независимых извлечений одного файла — каждое с readFileSync и четырьмя
регэкспами EXTRACT. Замечание качества теста (verified-находка confirm-рана
crossreview-adoption/01, 2026-10-05): на корректность не влияет, прогон
секунды; фикс — гигиена, чтобы тест не приучал к повторному чтению.
Байт-проверки идентичности копий и все кейсы остаются как есть.
