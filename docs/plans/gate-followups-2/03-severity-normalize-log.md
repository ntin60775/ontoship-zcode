# 03: Severity-коалесинг логируется

**What to build:** когда ось или ревьюер вернули severity вне high/low и код
нормализовал его в medium, прогон называет это в conclusion — оператор
отличает «ось сказала medium» от «ось сказала ерунду, подставили medium».
Сегодня нормализация молчит; соседний случай коалесинга (пустые
оболочки-находки) уже прикрыт честным счётчиком и логом — этот выравнивается
с ним. Хвост verified-находки приёмки gate-followups/02. Оба review-воркфлоу
(гейт и код-ревью), счётчик по всем находкам прогона; при нуле вывода нет.

**Blocked by:** None (can start immediately).

- [x] нормализованные severity считаются; при N > 0 conclusion (или notCovered)
      обоих review-воркфлоу называет число
- [x] при N = 0 вывод не мусорит
- [x] матрица: якорь на счётчик, негатив-проба ловит его исчезновение
- [x] `gitmark lint` + `pytest` зелёные
