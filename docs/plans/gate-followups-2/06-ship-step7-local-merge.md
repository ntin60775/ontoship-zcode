# 06: Шаг 7 скилла /ship синхронен формализованному git-флоу

**What to build:** шаг 7 скилла `/ship` обещает «local branch when there is no
remote; MR when there is» — при наличии remote предписывает MR, тогда как
формализованный флоу (docs/ops/git-flow.md, решение оператора 2026-10-06) —
локальный `--no-ff` мерж в `dev` всегда, MR только по явному решению оператора
в конкретном проекте (в паре со стоп-поинтом `stop-after-mr`). Формулировка
шага 7 и секция Honest degradation синхронизируются с рунбуком: три
отступления-константы (MR нет, отдельного прод-контура нет, remote может
отсутствовать) живут в рунбуке, шиппинг-ноут ссылается на него одной строкой
вместо переоткрытия в каждом прогоне. Правило «отступление никогда не
молчит» сохраняется — ссылкой, а не удалением. Код и воркфлоу гейта не
меняются: дифф тикета — только текст `skills/ship/SKILL.md`.

**Blocked by:** None (can start immediately).

- [x] шаг 7: локальный мерж в `dev` при любом контуре; MR — только если план
      или проект явно назначил (упоминается вместе со стоп-поинтом
      `stop-after-mr`)
- [x] Honest degradation называет отступления-константы ссылкой на
      docs/ops/git-flow.md; правило «не молча» не ослаблено
- [x] дифф тикета не задевает код и воркфлоу (только SKILL.md)
- [x] `gitmark lint` + `pytest` зелёные
