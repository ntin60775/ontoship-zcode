# 04: Порт to-tickets + критерии неделимости Q1–Q7

**What to build:** план в zcode разбивается на тикеты нативным скиллом: промоция
файла в папку (`git mv`, перелинковка), NN-файлы тикетов с блокирующими рёбрами,
таблица в README плана, квиз оператору — и встроенные критерии неделимой
логической единицы, чтобы «too coarse» ловилось до публикации.

**Blocked by:** 01 (скилл должен быть виден в воркспейсе для догфуда).

- [ ] Скилл `to-tickets`: шаги omp-версии (промоция, перелинковка входящих,
      индексная строка, шаблон тикета, lint+reindex, стоп без /ship) без omp-путей
- [ ] Критерии неделимости интегрированы в шаг разбивки: единица = проверяемая
      возможность; ДРОБИТЬ (≥2 независимых обещания; приёмка требует механику вне
      `depends_on`); СЛИТЬ (ничего нового сверх соседа); wide refactor —
      исключение; DAG без циклов, три места фиксации рёбер сходятся
- [ ] Приёмочный прогон — **хвост этой очереди**: скилл разбивает Tail-список
      плана queue-2 на тикеты (его первая настоящая работа); в папке уже
      01–04, хвост нумеруется с max(NN)+1 (с 05), не с 01 — дубль префикса
      `01-` lint не ловит
- [ ] `gitmark lint` + `pytest` зелёные
