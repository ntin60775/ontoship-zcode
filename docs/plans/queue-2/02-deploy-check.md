# 02: deploy-check — валидация вендоренной раскладки

**What to build:** проверка развёртывания одной командой: `deploy-check.sh` в
проекте с задеплоенным плагином подтверждает, что вендоренный код на месте и
работает — зелёный на живом деплое, `[FAIL]` на сломанной.

**Blocked by:** 01 (проверяется вендоренная раскладка из самодеплоя).

- [x] `scripts/deploy-check.sh` (в репо плагина, запуск — из проекта-потребителя):
      пакетные пути по журналу/маппингам — `.zcode/skills/kb-search/gitmark.py`,
      `.zcode/defaults/roles.md`, `.zcode/deployed.json`; без omp-путей
- [x] Движок работает из вендоренного пути: index/search смоук в cwd проекта
- [x] Роли: `roles.py resolve` из `.zcode` находит дефолт
- [x] SQLite FTS5 обязателен, trigram опционален (WARN)
- [x] Прогон: зелёный на самодеплое из тикета 01; ручная порча вендоренного файла
      даёт `[FAIL]` и exit 1

**Отгружено (2026-09-30).** Коммиты `3ea5a93` (worktree `ship/queue2-02-deploy-check`),
`240fed0` (release 0.5.3), `b0d59ea` (self-update); FF-мерж в main, релиз `v0.5.3`,
