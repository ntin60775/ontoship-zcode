# 01: Установка из локальной директории + видимость в воркспейсе

**What to build:** оператор открывает любой проект в zcode, ставит плагин ontoship
из локальной директории репозитория — и скиллы (`/kb-search`, `/doc`, `/ship`,
`/roles`, `/grilling`, `/init`) доступны по слэшу; путь установки и проверка
зафиксированы runbook'ом в KB плагина.

**Blocked by:** None (can start immediately).

- [ ] Runbook `docs/ops/install.md`: добавить marketplace из локальной директории
      (Discover → «+»), установить/включить плагин, проверить видимость скиллов
- [ ] Прогон runbook на реальном воркспейсе: скиллы вызываются по слэшу, роли
      резолвятся (`roles.py resolve`), `/kb-search` ищет по KB воркспейса
- [ ] Задокументирован dev-режим для самого репозитория плагина (зеркало
      `.zcode/skills` → `skills/*`, незакоммиченное) — чтобы правки скиллов
      догфудились без переустановки
- [ ] `gitmark lint` + `pytest` зелёные
