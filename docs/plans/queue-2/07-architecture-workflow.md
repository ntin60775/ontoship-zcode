# 07: architecture workflow — скан в фоне

**What to build:** архитектурный скан репо исполняется как фоновый workflow:
карта модулей и связей, точки дрейфа от задокументированной архитектуры,
отчёт оператору; сессия не блокируется на время скана.

**Blocked by:** None (can start immediately).

- [x] workflow-файл существует; скан уходит в фон и не блокирует сессию
- [x] отчёт по реальному репо: модули, связи, расхождения с KB-документацией
- [x] `gitmark lint` + `pytest` зелёные

**Решения прогона (2026-10-02).** Портирована только скан-часть omp-прототипа
(mp-improve-codebase-architecture): карта модулей/связей + дрейф против KB как
фоновый workflow; интерактивный гриллинг кандидатов остаётся интерактивным и в
ран не входит. Форма — двухрановая, как у /code-review: scan-ран
(скелет `git ls-tree/log/ls-files` → чтецы KB → мапперы областей → один
drift-хантер → артефакт «map» + сырые находки) и общий confirm-ран
(`../ship/confirm.workflow.ts`, report:"markdown") — третий потребитель общей
конфирмер-машины, no split-brain. Потолки: 12 областей, 15 KB-доков
(README/AGENTS/CONTEXT → docs/ вне plans/ → прочий md), 10 обещаний/док,
8 модулей/область, 12 находок; `.zcode/` исключён, docs/plans исключён —
всё с честными счётчиками. Приёмочный прогон по этому репо: карта 18 модулей /
57 связей, 142 обещания из 15 доков; 6 сырых дрейф-находок конфирмеры
опровергли 6/6 — drift-хантер на `qwen35b$high` принял выдумки мапперов
(«37 тестов», «1283 строки») за «обещания KB»; честный ноль дрейфа.
Наблюдение к вопросу о ролях: шум qwen35b на генеративных шагах ~100% в этом
ране (в ране 14 — ~30%); решение о переназначении ролей — за оператором,
в ран не вмешивались. Гейт шага 6: 12 сырых → 10 verified (закрыты: redact
на result.map и промпт хантера — единственные egress без редакции; пропуск
drift при живых связях; молчаливый `git ls-files`; SKILL.md — стабильные
маркеры abort, fallback артефакта, `stop_reason: user`, basename в ticket) /
2 unconfirmed (формулировки, опровергнуты контекстом). Отложено с
основаниями: concurrency-лимит `Promise.all` — репо-идиома (code-review/
confirm так же), рантайм сам адаптирует fan-out; `{4,}` в redact — baseline,
владелец тикет 15. Отступления от полного лупа: E2E = приёмочный прогон
(деплой-контура у плагина нет — шаг 8 это suite); dev-проверка — локальная
ветка dev без MR (релизный цикл репо — worktree → гейты → main,
docs/ops/install.md). Качество карты: (корень)-маппер частично вышел за свою
область (дубли модулей skills/ по маппингам deploy.json — дедупа модулей между
областями нет), CJK-вставки qwen35b в двух связях — в фоллоу-ап, не чинилось
после приёмки (правило финальной версии).
