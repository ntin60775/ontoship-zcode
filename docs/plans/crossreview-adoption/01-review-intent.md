# 01: Intent диффа в осях /code-review

**What to build:** ручной `/code-review` принимает замысел изменения (intent: 1–3
предложения — что этот дифф должен делать и что не должно меняться), и обе оси
каждого файла ревьюят дифф с этим замысла контекстом — как ревьюер ship-гейта
получает тикет. Без intent прогон не отказывает, а честно называет себя в итоговом
выводе ревью самосогласованности (замысел не передан). Закрывает асимметрию:
сегодня confirm-ран получает args.ticket, а оси-ревьюеры — нет, ревьюер слеп к
замыслу, проверяющий — нет (правило brief'а кросс-ревью: без замысла ревьюер
проверяет самосогласованность, а не то, что просили).

**Blocked by:** None (can start immediately).

- [ ] `code-review.workflow.ts` принимает необязательный `args.intent`; intent
      попадает в промпт каждой оси-задачи (filePrompt) обоих осей всех файлов
- [ ] пустой intent не валит прогон: conclusion честно помечает «ревью без
      замысла — проверена самосогласованность»
- [ ] `skills/code-review/SKILL.md` шаг 2 передаёт intent в args CreateWorkflow
      (оператор формулирует или берёт из тикета плана)
- [ ] живой прогон `/code-review` с intent на небольшом диффе: замысел виден
      осям (логи/промпты рана), находки не регрессировали против прогона без intent
- [ ] `gitmark lint` + `pytest` зелёные
