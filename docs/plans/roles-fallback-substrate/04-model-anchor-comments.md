# 04: Чистка модельных якорей из комментариев живого кода

**What to build:** комментарии в живом коде несут текущий constraint, а не
летопись: имена моделей и тарифов вычищаются там, где constraint
формулируется от физики задачи. Два места, переживающие демонтаж
direct-ветки, переписываются без имени модели с сохранением самого
constraint (контекст одного агента не зависит от размера полного диффа;
разбивка всегда) и provenance-ссылок на решение с датой. Архивированные
планы docs/plans/** не трогаются — архивирование их единственная работа.

**Blocked by:** 03 (обе правки в файлах, которые тяжело правит демонтаж;
один чурн — один рун).

- [ ] В `skills/**` нет упоминаний списанной модели ни в коде, ни в
  комментариях (проверка регистронезависимым поиском по skills/ чиста);
  комментарий о тарифе внутри direct-ветки уже исчез вместе с ней (03).
- [ ] В двух переписанных комментариях constraint сохранён и сформулирован
  от физики задачи, без имени конкретной ЛЛМ; ссылки на решение с датой и
  номером тикета остались на месте.
- [ ] `gitmark lint --strict` зелёный; вендор `.zcode/` доедет self-update.
