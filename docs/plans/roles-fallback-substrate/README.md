# Честные роли с фолбэком и демонтаж прямого API-субстрата

## Goal

Роли перестают врать пользователю, прямой API-контур линз демонтируется до
нуля клиентов, модельные якоря вычищаются из кода. Решения оператора
2026-10-09 (нитка «линзы/роли при нормальных моделях»):

- **Роль ≠ LLM.** Роль — слот с семантикой; модель — назначаемый ресурс.
  Роли не равны даже на одной модели: различие живёт в промптах и задаче.
- **Колонка модели = источник истины.** Ран роли идёт на назначенной модели
  всегда; «не тянет» → один чистый перезапуск рана на модели спец-роли
  `fallback` с громкой пометкой деградации, не молча. Роль `fallback` —
  константа-хранилище фолбэк-LM, в штатных назначениях не участвует.
- **Нерезолвящееся — не деградация.** Модель, которой нет на хосте
  (ListModels), остаётся fail-closed стопом до запуска; фолбэк ошибки
  конфигурации не маскирует.
- **Транспорт линз — только штатные субагенты.** Ветка `substrate=direct`
  (ND CALL, LENS_PROFILES, пул, таймауты, JSON-ремонт, ручной redact)
  сносится целиком; `classifyLensOutcome` адаптируется на исходы субагентов.
- **Узость ростка линз — принцип, не компенсация.** Ростер шести осей не
  трогается: узкий фокус — основная роль линз, а не ограничение из-за
  модели (решение оператора; агрегация ростера отвергнута).
- **Хардкод и якоря qwen — снос.** Дефолт `reviewerModel`, LENS_PROFILES-запись,
  arg-описание, имена моделей в комментариях живого кода. Комментарий несёт
  текущий constraint; летопись живёт в docs/plans и git history; provenance
  решений (дата, тикет) в комментариях остаётся.
- **qwen3.6-unlim-xl списан.** Неудачное вложение денег, полезный опыт
  (паттерн прямого API, факт «тариф ≠ карточка», finish=length-протокол
  coverage). Причина: потолок входа тарифа 138 336 ниже базового веса
  субагента ~141k — не годился субагентом никогда.

## Constraints

- `stop-before-commit` (дефолт).
- Мораторий инвариантов движка (ADR invariant-moratorium) — не заводим.
- Пререквизит вне репо (оператор, до приёмки тикета 02): `/roles set reviewer
  GLM-5.3-Flash$high` и `/roles set challenger GLM-5.3-Flash$high` —
  user-слой; без этого тикет 02 ломает живой гейт (qwen не выживает
  субагентом).
- Ростер линз (6 осей), роутинг, инвариант файл×линза, coverage — не меняются.
- Байт-в-байт копии `contextHint`/`normalizeSeverity` не трогаются
  (синк ловит tests/diff_map.mjs).

- Карточка провайдера zcode потолков не несёт (apiKey/baseUrl/модели/уровни);

  постулат «окно ≥262k, вывод ≥131k» закрывает обе травмы (вход и вывод).
- Внутри одного CreateWorkflow модель субагентов одна на весь ран — смена
  модели = новый ран; поэтому фолбэк — уровень вызывающего скилла, а не
  скрипта воркфлоу.
- Дефолтный субагентный путь жив и доказан A/B (v0.5.39: 4/4 посева, полный
  coverage; старый direct 3/4 с finish=length ×2).
- Модельные отказы: транзиентные ретраит рантайм хоста; ContextLimit ловится
  в скрипте; детерминистские модельные — provider-stop всего рана (до скрипта
  не доходит) — единственный сигнал для фолбэк-перезапуска на уровне скилла.
- Хвосты-A/B v0.5.39 (memory ship-lens39-state): пул-хвосты умирают с
  direct-веткой, гигиена-литералы и guard-контейнмент — в перепись пин-теста.
