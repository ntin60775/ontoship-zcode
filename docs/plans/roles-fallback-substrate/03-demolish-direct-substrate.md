# 03: Демонтаж direct-субстрата линз — снос прямого API-контура целиком

**What to build:** гейт работает без прямого API вовсе: ветка
`substrate="direct"` сносится из ревью-воркфлоу вместе со всем её контуром —
прямые вызовы API, тарифная карта LENS_PROFILES, пул воркеров, таймауты,
компакт-ретраи, JSON-ремонт, ручной redact, проба субстрата. Аргументы
`substrate`/`reviewerModel`/`provider` исчезают из декларации вместе с
гардами перепутанных аргументов. Классификация исходов линз живёт на
ошибках субагентного субстрата. Топология не меняется: ростер шести осей,
роутинг, инвариант файл×линза, честный coverage.

**Blocked by:** 02 (пока шаг 6 не ведёт линзы на модель роли reviewer,
direct — единственный путь для моделей вне субагентного субстрата).

- [ ] В ревью-воркфлоу отсутствует прямой API-контур: absence-проба по
  маркерам direct-ветки и тарифной карты в файле ничего не находит; в
  декларации args нет substrate/reviewerModel/provider; typecheck новой
  версии воркфлоу хостом чист (прецедент dwfrun-79631a53).
- [ ] Пин-тест субстрата переписан: direct-пины снесены вместе с веткой;
  living-хвосты A/B v0.5.39 запинены (привязка констант гигиены к
  субагентной ветке вне тарифной карты, brace-контейнмент guard'а);
  пул-хвосты (идентичность задач драйвера, ветка N<cap) закрыты самим
  демонтажем — отражено в ноте прогона, пинов не требуют.
- [ ] Шаг 6 ship-скилла не содержит direct-инструкций (substrate,
  reviewerModel, provider, «конфигурация — не правка репо» для прямого API).
- [ ] docs/reference/dependencies.md: «Контура замены провайдера»
  переписан — смена модели роли это карточка zcode плюс `/roles set`,
  прямого API-пути больше нет; датированная запись о демонтаже.
- [ ] Приёмка живым прогоном: полный гейт (review + confirm) на модельном
  диффе проходит на субагентном субстрате; сьют зелёный; вендор `.zcode/`
  доедет self-update.
