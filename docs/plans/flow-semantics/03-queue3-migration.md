# 03: Миграция queue-3 в ишью-контур

**What to build:** тикеты 04, 05, 06 queue-3 переносятся в
`.zcode/ontoship/issues/` (содержание: источник, наблюдаемое поведение,
критерии приёмки, статус); план queue-3 → status: archived с пометкой
«механизм заменён ишью-контуром, flow-semantics» — административная
архивация, причина в Context; пункт 11 «Порядка выполнения» реестра
финализирован; инвентарь регенерирован. Перед миграцией полёты проверяются
живыми признаками (git worktree list, ветки ship/*, незакоммиченные правки
тикетных файлов), не статусной таблицей README; живой полёт откладывает
миграцию своего тикета до закрытия — план не архивируется, пока в нём жив
тикет заменённого механизма.

**Blocked by:** 02 — ишью-контур существует в текстах.

- [ ] Три ишью-файла существуют и несут содержание тикетов 04–06 (источник,
  поведение, критерии, статус; критерии выводятся верифицируемо даже из
  неполного draft)
- [ ] queue-3 README: status: archived, пометка о замене механизма;
  пункт 11 реестра финализирован
- [ ] Живая проба: git worktree list и git branch проверены перед
  миграцией, результат зафиксирован в отчёте
- [ ] Инвентарь регенерирован (queue-3 archived в таблице планов, строка
  не удалена), lint --strict чист — ни битых ссылок на старые пути, ни
  сирот
