# 02: Ship — ишью-хвост, чек провенанса, план-приёмка-аккорд

**What to build:** шип-ран оформляет находки вне границ ишью-файлом
`.zcode/ontoship/issues/NN-<slug>.md` (без frontmatter, вне KB:
наблюдаемое поведение, источник, почему отложено), а не тикетом; Input
отказывает плану без провенанс-строки (именованный отказ до всякой работы);
последний archived-тикет плана запускает план-приёмку — пост-фактум аккорд:
живой прогон всех план-критериев юнита, зелёный → план archived, красный →
план-починка (новый тикет или переоткрытие); файл-планы: Goal/Done — спека
среза, приёмка вырождается в существующее поведение — названо явно;
административная архивация (упразднение механизма) — именованный класс с
записью причины в Context; handoff-слепок несёт счётчик открытых ишью.

**Blocked by:** 01 — формат провенанс-строки определён там.
