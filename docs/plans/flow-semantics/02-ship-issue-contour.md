# 02: Ship — ишью-хвост, чек провенанса, план-приёмка-аккорд

**What to build:** шип-ран оформляет находки вне границ ишью-файлом
`.zcode/ontoship/issues/NN-<slug>.md` (без frontmatter, вне KB:
наблюдаемое поведение, источник, почему отложено), а не тикетом; Input
отказывает плану без провенанс-строки (именованный отказ до всякой работы);
последний archived-тикет плана запускает план-приёмку — пост-фактум аккорд:
живой прогон всех план-критериев юнита, зелёный → план archived, красный →
план-починка (новый тикет или переоткрытие); файл-планы: Goal/Done — спека
среза, приёмка вырождается в существующее поведение — названо явно;
административная архивация (упразднение механизма) — именованный класс с
записью причины в Context; handoff-слепок несёт счётчик открытых ишью.

**Blocked by:** 01 — формат провенанс-строки определён там.

- [ ] ship SKILL.md: ишью-хвост (находка вне границ → ишью-файл, не тикет),
  чек провенанса в Input, план-приёмка-аккорд в шаге 9, счётчик ишью в
  handoff-слепке, класс административной архивации — grep-якоря
- [ ] Живая проба: /ship на плане без провенанса → именованный отказ на
  Input
- [ ] Живая проба: симулированная находка вне границ → ишью-файл создан по
  формату (наблюдаемое поведение, источник, почему отложено)
- [ ] Сьют и lint --strict зелёные

## Reel

- Цель (дословно: «все замечания и прочее что выясняется в ходе выполнения
  плана и что нельзя/не стоит править в рамках выполнения плана
  оформляется как ишью в гит») → Вход: шип-ран с верифицированной находкой
  вне границ тикета → Наблюдаемый выход: файл
  .zcode/ontoship/issues/NN-<slug>.md создан; тикет не заводится
- Цель (парафраз): ишью-файл несёт фиксированный формат → Вход: чтение
  созданного ишью-файла → Наблюдаемый выход: frontmatter нет; в теле три
  смысловых блока — наблюдаемое поведение, источник, почему отложено; файл
  вне KB, KB-инварианты целы
- Цель (дословно: та же первая) → Вход (краевой): находка, которую можно и
  стоит править в рамках плана → Наблюдаемый выход: правка внесена в
  рамках плана; ни ишью-файл, ни тикет не создаются
- Цель (дословно: «план обязан поставлять ровно один , целостный и
  минимально неделимый юнит функциональности.») → Вход: последний тикет
  плана получает status: archived → Наблюдаемый выход: живой прогон всех
  план-критериев юнита; зелёный → план archived
- Цель (дословно: «причём факт проверки выполнинения этого юнита всегда
  должен выражаться чётким набором критериев которые легко верифицировать
  для гоал флоу плана») → Вход (краевой): живой прогон падает хотя бы на
  одном план-критерии → Наблюдаемый выход: план не архивируется; открыта
  план-починка — новый тикет или переоткрытие
- Цель (парафраз): гарантия грилла действует на входе исполнения → Вход
  (краевой): /ship на плане без провенанс-строки → Наблюдаемый выход:
  именованный отказ на Input до всякой работы
- Цель (парафраз): файл-планы не запускают аккорд → Вход (краевой): шип
  файл-плана, Done-критерии среза выполнены → Наблюдаемый выход:
  план-приёмка не запускается, вырождение названо явно в выводе рана/слепке
- Цель (парафраз): открытые ишью видны между ранами → Вход (краевой):
  финал ship-рана при непустом .zcode/ontoship/issues/ → Наблюдаемый
  выход: handoff-слепок называет счётчик открытых ишью

Отклонённые случаи контрслоя: нет.
