# 01: Носитель цитат — дословные формулировки оператора в контракте

**What to build:** после грилла контракт несёт в `Context` блок дословных формулировок оператора — маркированные цитаты; при запуске по теме без контракта источником служат слова оператора из аргумента запуска; при отсутствии источника Цель помечается парафразом. Все следующие прогоны (разбивка, контрслой) берут Цели ленты только из этого блока — цитате больше негде умереть на стыке сессий.

**Blocked by:** None (can start immediately).

- [ ] Правило носителя записано в grilling SKILL шаг 7: блок дословных цитат в `Context` контракта + маркер парафраза при отсутствии источника — grep по скиллу находит формулировку.
- [ ] Живая проба: прогнанный грилл на тестовой идее пишет контракт, в `Context` которого grep находит блок цитат с маркерами дословности (или помеченный парафраз — маркер виден).
- [ ] pytest и lint --strict зелёные; лог прогона прочитан (счётчики, первый упавший), пины grilling-литералов в тесте модельных колонок целы.
