# 01: Носитель цитат — дословные формулировки оператора в контракте

**What to build:** после грилла контракт несёт в `Context` блок дословных формулировок оператора — маркированные цитаты; при запуске по теме без контракта источником служат слова оператора из аргумента запуска; при отсутствии источника Цель помечается парафразом.
