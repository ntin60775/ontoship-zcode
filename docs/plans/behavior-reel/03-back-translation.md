# 03: Контрслой — обратный перевод, сверка цитат, враждебные примеры, пробы посева

**What to build:** слепой прогон роли challenger по черновикам тикетов до квиза (новый воркфлоу-файл рядом с to-tickets SKILL + проза запуска одним чурном): восстанавливает «что система будет делать» и диффит с лентой (ловец внутренних противоречий — честная рамка, не более), посимвольно сверяет Цели ленты с эталоном цитат контракта (ловец подмен формулировок), предлагает ≥1 враждебный случай на тикет — то, что критерии обещают, а лента упускает (эталон входа: критерии + цитаты); ноль находок назван «не найдено», не пропущен; отклонённые оператором случаи остаются в Reel тикета именованными. Приёмка — посев по канону lens-substrate-flash: список посева — артефакт до рана; два класса посева — искажённая цитата в Цели и изъятый известный случай; исход двусторонний; посев живёт в копии черновика, публикация — после исхода пробы.

**Blocked by:** 02 — формат ленты и маскирование входа.

- [x] Воркфлоу контрслоя прогоняется на приёмочном материале и возвращает два класса именованных расхождений — рестатизация vs лента и сверка Целей с эталоном; ноль назван «не найдено» — видно в выводе рана.
- [x] На приёмочном материале прогон называет ≥1 враждебный случай на тикет — случаи, которых в ленте нет.
- [x] Посевная проба двусторонне зелёная: все посевы обоих классов названы именованными расхождениями; непосевных расхождений ≤ 2× числа посевов; список посева существовал до рана (артефакт).
- [x] Контрольная рука без контрслоя посевы не называет.
- [x] pytest и lint --strict зелёные; лог прогона прочитан (счётчики, первый упавший).

- Дизайн: слепота рестатизатора структурная (сборщик аска не принимает ленту
  и цитаты); сверка цитат — механическая, кодом (точное равенство строки);
  три аска на тикет (рестатизатор → дифф, враждебные — параллельно);
  именованные отказы сборки (маскирование, формат маркеров, парность NN,
  носитель, преамбула, формат номеров, маркеры фенсов) до первого аска.
- Уроки: жадный regex на буллет носителя молча портил двухпарные строки —
  класс символов `[^«»]+` + именование нераспарсенных; «строка-цель» обязана
  быть буллетом — проза шаблона и отклонённые случаи иначе обвиняют честный
  тикет; форма ответа модели (отказ/без массива/мусорные элементы) проверяется
  явно — иначе деградация неотличима от честного «не найдено»; ленивый
  квантификатор не спасает от backtracking — класс символов спасает.
