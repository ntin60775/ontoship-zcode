# 03: Контрслой — обратный перевод, сверка цитат, враждебные примеры, пробы посева

**What to build:** слепой прогон роли challenger по черновикам тикетов до квиза (новый воркфлоу-файл рядом с to-tickets SKILL + проза запуска одним чурном): восстанавливает «что система будет делать» и диффит с лентой (ловец внутренних противоречий — честная рамка, не более), посимвольно сверяет Цели ленты с эталоном цитат контракта (ловец подмен формулировок), предлагает ≥1 враждебный случай на тикет — то, что критерии обещают, а лента упускает (эталон входа: критерии + цитаты); ноль находок назван «не найдено», не пропущен; отклонённые оператором случаи остаются в Reel тикета именованными. Приёмка — посев по канону lens-substrate-flash: список посева — артефакт до рана; два класса посева — искажённая цитата в Цели и изъятый известный случай; исход двусторонний; посев живёт в копии черновика, публикация — после исхода пробы.

**Blocked by:** 02 — формат ленты и маскирование входа.

- [ ] Воркфлоу контрслоя прогоняется на приёмочном материале и возвращает два класса именованных расхождений — рестатизация vs лента и сверка Целей с эталоном; ноль назван «не найдено» — видно в выводе рана.
- [ ] На приёмочном материале прогон называет ≥1 враждебный случай на тикет — случаи, которых в ленте нет.
- [ ] Посевная проба двусторонне зелёная: все посевы обоих классов названы именованными расхождениями; непосевных расхождений ≤ 2× числа посевов; список посева существовал до рана (артефакт).
- [ ] Контрольная рука без контрслоя посевы не называет.
- [ ] pytest и lint --strict зелёные; лог прогона прочитан (счётчики, первый упавший).
