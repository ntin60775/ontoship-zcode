# 02: Лента в тикетах — секция Reel, квиз на примерах, маскирование входа контрслоя

**What to build:** `/to-tickets` выпускает тикеты с секцией Reel после чеклиста критериев — минимум два примера «Цель (цитата из блока 01) → Вход → Наблюдаемый выход»: нормальный и краевой/ошибочный; квиз разбивки предъявляет оператору примеры, не только заголовки; DoD-проход требует пример у каждого критерия — класса «не иллюстрируемо» нет, критерий без примера дорабатывается; правило маскирования: вход будущего контрслоя собирается из тикетов без секции Reel, лента и цитаты-эталон подаются отдельными входами.

**Blocked by:** 01 — Цели примеров цитируют блок носителя.

- [x] Шаблон тела тикета в to-tickets SKILL содержит секцию Reel после чеклиста критериев — grep находит.
- [x] Правило маскирования записано в том же скилле: вход контрслоя — тикеты без секции Reel; лента и цитаты — отдельные входы — grep находит.
- [x] DoD-проход (шаг 4) требует пример у каждого критерия; формулировка закрытия класса «не иллюстрируемо» в скилле — grep находит.
- [x] Живой прогон разбивки на тестовом плане: каждый тикет несёт ≥2 примера; Цели цитируют блок `Context` (или несут помеченный парафраз — маркер виден в тикете).
- [x] pytest и lint --strict зелёные; лог прогона прочитан (счётчики, первый упавший).
