## Goal

Сдвинуть точку контакта оператора с прозы на поведение: до кода оператор утверждает
конкретные примеры «Цель (дословная цитата) → Вход → Наблюдаемый выход», после кода те
же примеры — эталон приёмки. Закрыть ось False Attribution (подмена тезиса; Arena
Alignment Index: misquoted requests — самый частый режим FA) там, где она сегодня
держится только на внимательности читающего прозу.

## Done

- Носитель цитат: после прогона /grilling в `Context` контракта лежит блок дословных
  формулировок оператора маркированными цитатами — grep контракта находит блок;
  Цели ленты в тикетах берутся только из него; при отсутствии источника (topic-прогон)
  Цель — помеченный парафраз, и квиз это показывает.
- Формат Reel: шаблон тела тикета содержит секцию Reel после чеклиста критериев;
  каждый тикет с наблюдаемым поведением несёт ≥2 примера (нормальный + краевой);
  класса «не иллюстрируемо» нет — критерий, не породивший пример, доработан на
  DoD-проходе (наблюдаемый факт предъявим тройкой по определению — прецедент
  redact-матрицы).
- Квиз на примерах: шаг 3 /to-tickets предъявляет разбивку примерами ленты, не только
  заголовками.
- Маскирование: вход контрслоя собран из тикетов без секции Reel; лента и
  цитаты-эталон поданы отдельными входами — видно в args рана.
- Контрслой: `skills/to-tickets/back-translation.workflow.ts` на приёмочном материале
  возвращает два класса именованных расхождений — рестатизация поведения vs лента
  (внутренние противоречия) и посимвольная сверка Целей с эталоном цитат (подмены
  формулировок); ноль находок назван «не найдено», не пропущен.
- Враждебные примеры: прогон контрслоя на приёмочном материале называет ≥1 случай,
  который критерии обещают, а лента упускает; отклонённые оператором случаи остались
  в Reel тикета именованными.
- Ship: строка stop-before-commit несёт по каждому примеру ленты фактически
  наблюдённый вывод живого E2E (шаг 8) в форме «обещано → фактически» — без
  самоотчёта «совпало»; тикет без Reel даёт «Reel: отсутствует»; tests-линза
  ревьюера сверяет тесты с Reel.
- Приёмка посевом (уровень 1 иерархии, канон lens-substrate-flash): список посева —
  артефакт до рана; два класса посева — искажённая цитата в Цели и изъятый известный
  случай; исход двусторонний: все посевы названы именованными расхождениями,
  непосевных расхождений ≤ 2× числа посевов; посев жил в копии черновика, публикация
  тикетов — после исхода пробы; контрольная рука без контрслоя посевы не называет.
- Фикстурная проба ship-половины: на тикете-фикстуре с искажённой лентой стоп-поинт
  называет расхождение именованно.
- pytest и lint --strict зелёные; пины test_run_model_column.py:92-115 не тронуты.

- Мораторий соблюдён по прецеденту evidence-discipline: новых механизмов движка,

  поведением; контрслой обязателен на каждом прогоне с контрактом; объём — один план.

## Context

- Источник — разбор Arena Alignment Index (arena.ai/blog/ai-alignment-index,
  90 000 сессий, 27 моделей): misquoted requests — самый частый режим False
  Attribution. Тезис оператора: человеку нереально глазами контролить всю писанину
  агента — медиум утверждения должен быть тем, в котором человек силён.
- Грилл 2026-10-13: красная команда dwfrun-cdf168fe (challenger GLM-5.3-Flash$high;
  9 решений → 8 substantial, 1 minor) вскрыла четыре дыры черновика, закрытые
  пере-решениями: (1) дословной цитате негде жить через стык сессий — дайджест
  грилла не персистится, /to-tickets читает только контракт → носитель — Context
  контракта; (2) слепая рестатизация на той же модели — сходящаяся задача,
  интерпретационную подмену не ловит → рестатизация честно понижена до ловца
  внутренних противоречий, подмены формулировок ловит посимвольная сверка с
  эталоном, cherry-picking — посев изъятия; (3) «совпало M» — самоотчёт 4-го уровня
  → стоп-поинт несёт только факты E2E «обещано → фактически»; (4) проба сеяла
  мутант в вход детектора → маскирование входа, посев в копии, список до рана,
  двусторонний критерий.
- Честная граница (фиксируется прозой в SKILL): при ролях на одной модели
  интерпретационная подмена оператор→тикет машинно префильтруется только сверкой
  цитат; полная сила контрслоя — с появлением второй семьи моделей в реестре ролей.
- Порядок: 01 grilling (носитель), 02 to-tickets (формат+квиз+маскирование),
  03 контрслей+пробы посева (SKILL+workflow одним чурном — канон «один файл — один
  чурн» о продакшн-файле, прецедент onto-doc-hygiene), 04 ship (+фикстурная проба).
