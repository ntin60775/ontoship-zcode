# 04: Ship — дифф ленты фактами E2E, tests-линза, ветка отсутствия, фикстурная проба

**What to build:** стоп-поинт `stop-before-commit` показывает по каждому примеру ленты фактически наблюдённый вывод живого E2E (шаг 8) в форме «обещано → фактически» — без самоотчёта исполнителя «совпало»; тикет без секции Reel даёт строку «Reel: отсутствует»; tests-линза гейта получает обязанность сверять тесты с Reel; расхождение закрывает только оператор. Приёмка ship-половины — фикстурная проба.

**Blocked by:** 03 — линейность ради якорей и порядка ревью (функциональной зависимости от контрслоя нет — решение квиза 2026-10-14).

- [x] Правило в ship SKILL: строка стоп-поинта несёт факты E2E по примерам ленты («обещано → фактически»), самоотчёт «совпало» запрещён; ветка «Reel: отсутствует» для тикетов без ленты — grep находит обе формулировки.
- [x] tests-линза в воркфлоу ревьюера получает обязанность сверять тесты с Reel — grep по воркфлоу находит.
- [x] Фикстурная проба: тикет-фикстура с искажённой лентой — стоп-поинт называет расхождение именованно (проба воспроизводима по артефакту рана).
- [x] pytest и lint --strict зелёные; лог прогона прочитан (счётчики, первый упавший), пины ship-литералов в тесте модельных колонок целы.
