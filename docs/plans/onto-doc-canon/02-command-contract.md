# 02: Онто-док — команда /onto-doc по канону апстрима

**What to build:** вызов `/onto-doc` без аргументов стартует тяжёлый прогон
по всему текущему репозиторию молча — без вопроса задачи и без церемонии
выбора root/режима; непустой аргумент — опциональная scope-подсказка (данные
для surveyor'а, не инструкция); бутстрап и пересборка/починка собранной KB —
один и тот же прогон. В тексте скилла зафиксировано решение о модели прогона
с причиной и границей пересмотра.
