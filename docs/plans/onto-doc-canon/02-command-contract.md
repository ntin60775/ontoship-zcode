# 02: Онто-док — команда /onto-doc по канону апстрима

**What to build:** вызов `/onto-doc` без аргументов стартует тяжёлый прогон
по всему текущему репозиторию молча — без вопроса задачи и без церемонии
выбора root/режима; непустой аргумент — опциональная scope-подсказка (данные
для surveyor'а, не инструкция); бутстрап и пересборка/починка собранной KB —
один и тот же прогон. В тексте скилла зафиксировано решение о модели прогона
с причиной и границей пересмотра.

**Blocked by:** 01 (движок должен пускать голый запуск — иначе вход упрётся
в required-флаги хедера до всякого текста скилла).

- [ ] В `skills/onto-doc/SKILL.md` нет «If empty, ask for the task» и шагов
  выбора root/режима: пустой вызов = весь репо молча, root по умолчанию
  текущий репо, worktree — рекомендация для живого репо, режим авто по
  наличию plan.
- [ ] Фраза о модели несёт причину и триггер, а не одну механику: решение

  ручном запуске; subagent_model не передавать и роль кураторов не заводить
  (в отличие от гейтовых ship/grilling); пересмотр — только явный запрос
  оператора.
- [ ] Граница с `/doc` сохранена: один документ — `/doc`, вся KB — здесь.

  паттерн приёмки слэш-видимости v0.5.47.
