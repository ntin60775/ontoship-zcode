## Goal

Каждый субагент воркфлоу читает модель из назначенной ему роли; роли —
единственный контур LLM субагентов (модель чата и хардкод литералов в
движках — не рычаги). Общий механизм: реестр ролей (механически готов) +
мост №1 — одноролевой ран на `subagent_model` роли (паттерн гейтов,
документируется) + мост №2 — многоролевой: конвенция плейсхолдеров
`{{ROLE_MODEL:<role>}}` в движке-шаблоне, инстанцируемом запускающим
агентом после resolve+ListModels, документируется как общий контракт в
скилле roles. Назначения онто-дока: кураторы fan-out и healer — роль
`curator` (GLM-5.3-Flash$high), surveyor — роль `surveyor`
(GLM-5.3-Flash$max). Правило записи: новая роль без специфики вносится
записью GLM-5.3-Flash**$max с явным level**; роли-исключения называются
поимённо с причиной.

## Scope

  `docs/reference/dependencies.md` (контур замены модели роли — дополнить
  пер-агентными моделями и мостом №2).
- `skills/onto-doc/SKILL.md` (шаг запуска + фраза о модели),
  `skills/onto-doc/onto-doc.workflow.ts` (плейсхолдеры ролей; промпты,
  фазы, hygiene-области и отчёт не трогаются), `tests/test_onto_doc_command_contract.py`,
  `tests/test_run_model_column.py`, `tests/test_roles.py`.
- `roles.py` — не трогаем: имена свободные, слои/провенанс/строгий парсер
  готовы (аудит 2026-10-13); неявный дефолт неизвестной роли в резолвер не
  заводится (грилл d3: опечатка в имени роли обязана падать, а не молча
  получать модель).
- Гейтовые скиллы (ship, code-review, architecture, grilling) не мигрируют:
  подтверждающий ран двухвидовой (confirmer-N + сводчик), но остаётся на
  мосту №1 целиком на confirmer — записанное исключение; миграция гейта на
  мост №2 — отдельный будущий тикет по явному запросу оператора.
- Вендор `.zcode/` руками не правится — доедет self-update на шаге деплоя.

## Constraints

- `stop-before-commit` (дефолт).
- Fail-closed без фолбэка: resolve ролей запуска, сверка с ListModels
  (exists/not disabled/level) и absence-стоп — всё ДО инстанциации;
  дифф-префлайт связывает инстанс с resolve машинно (не глазом оператора в
  окне подтверждения). Решение оператора 2026-10-13: «всё известно
  заранее».
- Компиляторский предел хоста (живой эксперимент 2026-10-13): persona.model
  обязан быть известен до старта рана — строка из args отвергается
  («A subagent's `model` must be known before the run starts: a string
  literal, a union of string literals, or a ModelRef from model("…")»).
  Динамические модели роли входят только мостом №1 (subagent_model,
  хост-валидация на сабмите) или мостом №2 (литералы, подставленные после
  resolve). Хардкод model()-литералов в статическом движке мимо ролей
  запрещён.
- Семантика онто-док прогона (survey → fan-out → lint-гейт → healer ≤ 4 →
  хвост) не меняется — только источник моделей; нового агента нет.
- Мораторий инвариантов: новых инвариантов и реестров не заводить.
