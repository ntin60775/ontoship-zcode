# 02: Онто-док на роли + перепись матрицы и тестов

**What to build:** прогон онто-дока читает модели субагентов из ролей:
кураторы fan-out и healer — `curator` (GLM-5.3-Flash$high), surveyor —
`surveyor` (GLM-5.3-Flash$max); агента-сводчика не заводим (решение
оператора 2026-10-13: «сводящий» = модель для surveyor), семантика прогона
не меняется. Движок становится шаблоном с плейсхолдерами, SKILL —
единственный вход через свежую инстанциацию. Матрица canon/02 и тесты
переписаны на новые вводные: сьют честно краснеет до переписи и зеленеет
после.

**Blocked by:** 01 (записи curator/surveyor и документированная конвенция
моста №2 — иначе SKILL ссылается на несуществующий контракт).
