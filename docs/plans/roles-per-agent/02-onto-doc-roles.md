# 02: Онто-док на роли + перепись матрицы и тестов

**What to build:** прогон онто-дока читает модели субагентов из ролей:
кураторы и healer — роль `curator` (GLM-5.3-Flash$high по дефолту слоёв),
«сводящий» — роль `synthesizer` (GLM-5.3-Flash$max; конкретный агент — по
гриллу: рекомендация surveyor, альтернатива — новый синтезатор отчёта).
Модель чата перестаёт быть рычагом прогона. Матрица контракта canon/02 и
тесты переписаны на новые вводные — сьют честно краснеет до переписи и
зеленеет после.
