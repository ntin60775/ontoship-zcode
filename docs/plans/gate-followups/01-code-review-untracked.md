# 01: Код-ревью видит untracked-файлы диффа

**What to build:** `/code-review` ревьюит весь дифф области, включая новые
(незакоммиченные) файлы — сейчас карта файлов строится только по tracked
истории, и untracked-файл выпадает из код-ревью молча (тот же класс дефекта,
что ship-гейт чинил в queue-2/16). Карта диффа дополняется untracked-файлами
из статуса worktree (с измерением размера и отсечкой бинарных, как в гейте);
ревьюер нового файла получает явное указание, что его дифф — весь файл; вывод
называет файлы, попавшие в ревью, и все именованные пропуски. Парсеры карты
диффа живут копией гейт-парсеров: копии байт-в-байт идентичны и проверяются
той же тест-матрицей (расширение redact-паттерна — копий несколько,
рассинхрон ломает прогон).

**Blocked by:** None (can start immediately).

- [x] код-ревью на диффе с новым (незакоммиченным) файлом ревьюит его наравне
      с изменёнными — живой прогон с новым файлом
- [x] вывод называет файлы, попавшие в ревью, и именованные пропуски
- [x] матрица парсеров проверяет идентичность всех копий; `gitmark lint` +
      `pytest` зелёные

**Shipping-note (2026-10-05).** Фича `4f83529`, гейт-фиксы `f0da6a0`, мерж в
dev `4a21203`, релиз v0.5.19. Критерий 1 закрыт живым прогоном нового
код-ревью на диффе worktree с untracked-scratch-probe: покрытие 3/3, probe
отревьюен обеими осями, заведомая находка (проглоченный `OSError → None`)
найдена и независимо подтверждена конфирмером запуском (probe после приёмки
удалён, в релиз не входит). Confirm приёмки: 8 сырых → 7 verified / 1
опровергнут (quotepath у `git status`: `-z` отдаёт не-ASCII пути сырым UTF-8
независимо от `core.quotepath` — подтверждено od-пробой и гейтом). Гейт
шага 6: 9 сырых → 4 verified закрыты (prompt-инъекция через имя файла —
недоверенные данные в системном промпте осей; `rev-parse --verify` базой —
abort называет причину; якорь `parseNumstat` в матрице и для источника;
`new Function` с graceful-диагностикой) / 5 опровергнуты воспроизведением
(директории при `-uall` раскрываются в файлы; ветки abort-текстов различают
сценарии; oversize-спред инвариантен; rename в numstat не теряется — 9
прогонов; ENOENT печатает полный путь). Ограничения приёмки: живой прогон
предшествовал гейт-фиксам — правки не касаются карты/покрытия (системный
промпт, rev-parse, тест-матрица). Два verified-находки приёмки на
пре-существующие строки (severity-коалесинг без лога, обязательность цитаты
промптом без enforcement кодом) — вне скоупа тикета, кандидаты в фоллоу-апы.
Матрица: идентичность копий байт-в-байт (паттерн redact-матрицы queue-2/15) +
якоря живых вызовов у источника и копии; негатив-пробы (мутация якоря
источника, обрыв тела по `\n}`) ловятся rc=1. Процессный урок прогона:
`git checkout --` по файлу с незакоммиченными правками снёс фикс-ы дважды —
восстановлено побайтово, перепроверено прогонами; в ship-прогонах — только
cp-бэкап-паттерн.
