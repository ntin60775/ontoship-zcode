# Субстрат линз гейта — дефолтные субагенты на модели конфирмера

## Goal

Линзы ревью-рана работают дефолтными субагентами zcode на модели конфирмера
(GLM-5.3-Flash$high) вместо прямых вызовов neuraldeep-API; прямой API остаётся
явным фолбэком для моделей, чей контекст не несёт базовый вес субагента.

## Done

- Живой A/B на реальном диффе (прецедент — приёмка external-dependencies/04):
  тот же дифф через старый субстрат (прямой API, qwen) и новый (субагенты
  Flash) — новый покрывает все пары файл×линза без единого finish=length,
  даёт сырые находки не хуже старого на том же диффе, typecheck новой версии
  воркфлоу хостом чист.
- reviewer.workflow.ts: линза = `agent()` с узкой персоной и материалом в ask
  (инвариант «один файл на вызов» сохранён), типизированный результат вместо
  JSON-в-фенсе; ND_CALL / LENS_PROFILES / repairJsonStrings остаются только в
  ветке фолбэка `args.substrate="direct"`.
- tests/test_reviewer_substrate.py адаптирован под новую топологию (пины
  фолбэк-веток сохранены).
- docs/reference/dependencies.md: тарифный факт с датой — план GLM-Flash несёт
  базовый вес субагента (~141k контракта+схем), подтверждено живыми ранами
  dwfrun-68730a08 и dwfrun-0f9b01df (2026-10-08, ноль отказов).

## Scope

- `skills/ship/reviewer.workflow.ts` (+ вендор `.zcode/` доедет self-update).
- `tests/test_reviewer_substrate.py`, `docs/reference/dependencies.md`.
- Роли: дефолт субстрата = модель роли confirmer; явный `args.substrate`
  переключает на прямой API.

## Constraints

- `stop-before-commit` (дефолт).
- Новый инвариант движка не заводится (мораторий, ADR invariant-moratorium).

## Context

Исследование 2026-10-08 (решение оператора: деградацию не принимаем, фолбэк —
GLM-5.3-Flash$high; выводы добора и confirm-ранов):

- Прямой API был вынужденным: базовый вес субагента ~141k токенов против
  потолка neuraldeep 138 336 — три provider-stop за день (2026-10-06). У плана
  zai этого потолка нет: confirm-ран dwfrun-0f9b01df (24+ сессий) и добор
  dwfrun-68730a08 отработали без единого отказа.
- qwen на прямом API: 6 провалов линз за два рана (finish=length — thinking+JSON
  не влезают в 8000 вывода), плюс история 429 (пул = 4), JSON-ремонтов и
  ручных ретраев. GLM-Flash на тех же материалах: 3/3 и 23/23, типизированные
  результаты без парсинга.
- Цена прямого субстрата в коде: инлайн-скрипт ND_CALL с fail-closed
  конфигом, карта LENS_PROFILES per-модель, извлечение/починка JSON, ручные
  таймауты — сотни строк, каждый новый тариф = запись в карту и наблюдение.
- Риск миграции: контекст Flash на гигантских диффах — смягчён действующими
  потолками MAX_DIFF_LINES/MAX_FILES; риск «блуждания» агента — жёсткий ask
  «весь материал в промпте, не отходи» (дисциплина confirm-ранов показана
  живьём).
- Экономика: гейт остаётся дорогим — принятый размен (Парето, ADR); миграция
  убирает класс отказов и обслуживания, а не токены как класс.
