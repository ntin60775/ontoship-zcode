# Риск-скейлинг гейта — доковые диффы проходят лёгкий контур

## Goal

Цена гейта масштабируется от риска диффа: изменения только в доках KB идут
лёгким контуром — review-ран с единственной стартующей docs-линзой (ростер по
appliesTo уже даёт это без изменений движка) и confirm-ран, запускаемый только
при ненулевых находках; любой файл вне `docs/**`-`.md` — полный контур, как
сегодня. Главный выигрыш лёгкого контура — процессный: доковый мерж прямо в
main по git-flow, без dev-цикла и релиза.

## Done

- skills/ship/SKILL.md шаг 6 несёт правило классификации по той же карте
  диффа, что меряет review-ран (numstat + untracked): лёгкий контур iff каждый
  файл карты лежит в `docs/**` и заканчивается на `.md`; тяжёлые названы
  явно — `skills/**` (включая `*.md`), `defaults/roles.md`, `.zcode/**`,
  корневые `README.md`/`AGENTS.md`, `deploy.json`, `package.json`,
  `.zcode-plugin/`, `hooks/**`, `scripts/**`, `tests/**`, `docs/ontology.md`.
- Шаг 6: в лёгком контуре при 0 находок и полном покрытии confirm-ран не
  создаётся (указание «pass the findings array as-is, even when empty»
  получает ветку doc-only); при находках — обычный confirm без изменений.
- Шаг 7 SKILL.md: doc-only тикет мержится доковым путём git-flow («Доковые и
  опс-коммиты»: прямо в main, без dev-мержа и релиза, suite + `lint --strict`
  перед пушем) — условная ветка вместо безусловного «merge into dev in every
  contour»; шаг 9: handoff-слепок честно пишет «доковый мерж, без dev-hash».
- Живая проверка обоих контуров: лёгкий прогон на реальном doc-only диффе —
  coverage review-рана называет ровно одну стартовавшую линзу `docs` и
  idle-список остальных, confirm при 0 находок не создавался (отражено в
  отчёте рана/шаге 7); полный прогон на кодовом диффе — два рана, как сегодня;
  в обоих провал файла именован отдельно от счётчика находок.
- Текст блока «Never skippable» SKILL.md идентичен прежнему; в лёгком прогоне
  AskUserQuestion на main-мерж задан (и на деплой, если есть).

## Scope

- `skills/ship/SKILL.md` — шаги 6, 7, 9 (вендор `.zcode/` доедет self-update).
- Без изменений движка и args воркфлоу (мораторий; ростер уже даёт docs-only).

## Constraints

- Новых инвариантов движка нет (мораторий); классификация живёт прозой скилла.
