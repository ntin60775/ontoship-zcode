# Риск-скейлинг гейта — доковые диффы проходят лёгкий контур

## Goal

Цена гейта масштабируется от риска диффа: изменения только в доках KB идут
лёгким контуром (docs-линза + confirm только находок), код движка/воркфлоу/
тестов — полным циклом, как сегодня.

## Done

- ship SKILL.md шаг 6 различает классы диффа: doc-only (изменения только в
  `docs/**` и планах) → один прогон docs-линзы и confirm-ран только по
  находкам; любой код (`skills/**`, `tests/**`, `hooks/**`, `scripts/**`)
  → полный двухрановый гейт без изменений.
- Классификация — детерминированное правило по списку файлов диффа, записано
  в SKILL.md словами (никакого нового флага движка — мораторий).
- Живая проверка обоих контуров: доковый дифф через лёгкий путь, кодовый —
  через полный; честность инвариантов сохранена в обоих (провал файла ≠
  «0 находок», пустой confirm честен).
- Лёгкий контур не касается никогда-не-пропускаемых окон (main/деплой).

## Scope

- `skills/ship/SKILL.md` (вендор `.zcode/` доедет self-update).
- При необходимости — `skills/code-review/SKILL.md` одной строкой про тот же
  принцип; тесты не требуются (правило прозы скилла, не код).

## Constraints

- `stop-before-commit` (дефолт).
- Новых инвариантов движка нет (мораторий); классификация живёт в скилле.

## Context

Ретроспектива 2026-10-08 (решение оператора «да»): цена гейта сопоставима с
ценой реализации; для доковых слайсов полный confirm-марафон избыточен —
находки docs-линзы это формулировки и синк имён, а не баги поведения
(онто-док-паритет: 4 доковых raw, из них 1 принята частично, 2 опровергнуты).
Прецедент разной тяжести уже есть: доковые мержи в main минуют dev и релиз
(git-flow.md «Доковые и опс-коммиты») — гейт догоняет ту же логику.
